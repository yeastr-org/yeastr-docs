yeastr.yam.yam_with_call_name(node, call, name)¶

IS A MACRO

Yeastr Ast Match: expr predicate:

Example: yam_with_call_name(ast_node, call, 'mElse')

Will match if ast_node would unparse like with mElse():

And, will bind a variable named ‘call’

And another one called literally ‘what’ (you can grab as name from)

Parameters:

  • node (ast.AST) – to test

  • call – a python name to be bound

  • name (str) – to test

Type:

call: object
